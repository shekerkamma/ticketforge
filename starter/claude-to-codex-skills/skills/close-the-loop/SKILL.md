# Close The Loop

## Workflow

1. Restate the question and answer.
2. Summarize the evidence, confidence, and caveats.
3. List:
   - decisions enabled
   - follow-up actions
   - owners or stakeholder audiences
   - unresolved questions
4. Save a concise closing note in the run directory.
