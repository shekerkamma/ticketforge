# Resume Analysis

## Workflow

1. Load the selected run directory.
2. Inspect what exists:
   - question brief
   - spec
   - findings
   - charts
   - packaged outputs
3. Identify the first incomplete stage.
4. Continue from there instead of restarting the whole analysis.
