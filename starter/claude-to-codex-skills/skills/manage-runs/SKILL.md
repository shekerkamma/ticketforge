# Manage Runs

## Workflow

1. Enumerate runs under `working/runs/`.
2. Show status:
   - active
   - blocked
   - complete
   - archived
3. Summarize outputs and missing pieces.
4. Suggest `resume-analysis`, `archive-analysis`, or `close-the-loop` when relevant.
