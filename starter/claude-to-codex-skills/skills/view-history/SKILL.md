# View History

## Workflow

1. Read the analysis archive or run index.
2. List recent analyses with:
   - date
   - title or question
   - dataset
   - confidence
   - output types
3. Support search by term, dataset, or timeframe.
4. Suggest `resume-analysis` if a relevant partial run exists.
